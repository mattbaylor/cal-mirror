The copy you can actually use

A subscribed feed can’t be reshared, recoloured or written into. A copy in your own account can, and it reaches your other devices by itself.

If the Calendar app can see it, Calendar Mirror can copy it: iCloud, Google, Microsoft 365, Exchange, any subscribed feed. No work login, no IT approval. Repeating events come across, anything you add to the copy stays put, and if you delete a pair the copies stay with you as ordinary events.

Silent when it works. Loud when it stops.

A working pair writes nothing into your calendar except the copies. If one stops, an all-day warning appears in the destination, so you find out on your phone without opening anything. It clears itself when the pair recovers.

On the Mac the icon in the menu bar wears whichever face fits: a smile while every copy is current, and something else only when there is something to say. The copy follows a change within moments, with a five-minute pass underneath to catch anything missed.

On iPhone and iPad the app shows every pair with its health and how many events it is minding. It refreshes in the background when iOS allows, and a pull down refreshes it now.

How fast a copy reaches your other devices is then up to iCloud.

A pair can also leave events behind: the ones you declined, all-day events, anything outside working hours. The README lists every rule. Tags in an event’s notes work only on events you can edit, which a subscribed feed is not.

AskWhen.me, if you want people to ask

A subscription you turn on inside Calendar Mirror. Your device publishes a few times to askwhen.me/yourpage; someone picks one and asks; nothing lands until you say yes. The server never sees your calendar.

Don’t take my word for it

The source is public and MIT-licensed. Read how a copy is made, check for yourself what leaves your device, or build the Mac version free:

git clone https://github.com/mattbaylor/cal-mirror.git
cd cal-mirror
./install.sh

The repository is called cal-mirror; the app is Calendar Mirror. Same code, same engine.
