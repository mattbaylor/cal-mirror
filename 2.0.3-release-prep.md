### Blocker 3: App Store Connect API key in GitHub Secrets is invalid
The GitHub secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (all created 2026-08-26) now return 401 from Apple.
The last successful release run was 2026-10-01. Between then and now there were no release attempts until today.

### Fix needed
Update the repository secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` with the current, valid App Store Connect API key.
(Note: this is the *App Store Connect API* key used by altool, separate from the *App Store Server API* key in Infisical.)
